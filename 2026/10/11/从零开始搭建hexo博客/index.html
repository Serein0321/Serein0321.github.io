首先需要为你的 GitHub 仓库安装 Utterances 应用：

  1. 访问 https://github.com/apps/utterances
  2. 点击 “Install”
  3. 选择 “Only select repositories”
  4. 选中你的博客仓库（如 Serein0321.github.io）
  5. 点击 “Install”

使用教程

先设置新建文章的默认模板

执行 hexo new "文章标题" 时，Hexo 会读取 scaffolds\post.md，根据它创建新文章。希望每篇文章自动带上评论开关、分类、标签和正文结构，就修改这个模板。

打开：

将文件内容替换为下面的模板，保存：

模板中的字段含义如下：

内容 新建文章时的作用
{{ title }} 自动替换为 hexo new 命令中填写的标题
{{ date }} 自动替换为创建文章的日期和时间
categories: [] 预留分类字段，暂时不分配分类
tags: [] 预留标签字段，暂时不分配标签
comments: true 默认允许文章显示评论组件；评论服务仍需按第 15 节配置
mathjax: false 默认不启用这篇文章的公式渲染，需要公式时改成 true
<!-- more --> 将前面的正文作为首页摘要
正文小标题 每篇新文章自动带上写作结构，可以按文章需要修改

常用命令汇总

命令 说明
hexo new "标题" 创建新文章
hexo generate 生成静态文件
hexo server 启动本地服务器
hexo deploy 部署到 GitHub
hexo clean 清理缓存
